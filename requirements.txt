# Requirements for the code in this textbook.
#
# You do NOT need all of this to start. Stages 0 to 3 use almost nothing but the
# Python standard library. Install packages as the chapters ask for them, or just
# install everything here once inside a virtual environment:
#
#     python -m venv .venv
#     source .venv/bin/activate      # on Windows: .venv\Scripts\activate
#     pip install -r requirements.txt
#
# The heavy machine-learning and quantum libraries (PyTorch, TensorFlow, Qiskit)
# are kept in a separate file so you are not forced to download gigabytes before
# you need them. When you reach Parts 14, 19, and 20:
#
#     pip install -r requirements-ml.txt
#
# Versions are intentionally left unpinned so the book keeps working over time.
# If you want a frozen, reproducible set, run `pip freeze > requirements.lock`.
# Python 3.10 or newer is recommended.
