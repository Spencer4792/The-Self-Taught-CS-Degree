## Git

> Everyday commands + undo recipes. Depth: **see Chapter 11.1** (internals) and **11.2** (hands-on tutorial).

| Task | Command |
|---|---|
| New repo / clone | `git init` · `git clone <url>` |
| Status / changes | `git status` · `git diff` · `git diff --staged` |
| Stage / unstage | `git add <f>` · `git add -p` · `git restore --staged <f>` |
| Commit | `git commit -m "msg"` · `git commit --amend` |
| Discard edits | `git restore <f>` (unstaged, destructive) |
| History | `git log --oneline --graph --decorate --all` · `git show <h>` |
| Who/why | `git blame <f>` · `git log -p <f>` |
| Branch | `git switch -c <b>` · `git switch <b>` · `git branch -d <b>` |
| Merge | `git merge <b>` · `git merge --abort` |
| Rebase | `git rebase main` · `git rebase --continue` / `--abort` |
| Remote | `git remote add origin <url>` · `git remote -v` |
| Sync | `git push -u origin <b>` · `git pull` · `git fetch --prune` |
| Stash | `git stash` · `git stash pop` · `git stash list` · `git stash -u` |
| Cherry-pick | `git cherry-pick <h>` · `--continue` / `--abort` |
| Tags | `git tag v1.0` · `git push origin v1.0` · `git tag -a v1.0 -m "..."` |
| Bisect | `git bisect start` · `git bisect bad` · `git bisect good <h>` |

**Undo recipes (most → least common):**

```
Discard unstaged edits to a file ......... git restore <file>
Unstage a file (keep edits) .............. git restore --staged <file>
Fix last commit msg / add forgot file .... git commit --amend [--no-edit]   (unpushed only)
Undo last commit, keep code staged ....... git reset --soft HEAD~1
Undo last commit, keep code unstaged ..... git reset HEAD~1           (--mixed, default)
Undo last commit AND discard code ........ git reset --hard HEAD~1    (DESTRUCTIVE)
Safely undo a PUSHED commit .............. git revert <hash>          (new inverse commit)
Recover a "lost" commit .................. git reflog  →  git reset --hard <hash>
Drop a file from tracking (keep on disk) . git rm --cached <file>
Force-push safely ........................ git push --force-with-lease
```

Rule: **`reset`/`amend`/`rebase` = local only.** Anything pushed & shared → use **`revert`**.

## SQL

> SELECT / JOIN / GROUP BY / windows / DDL. Depth: **see Chapter 14.x** (databases & SQL).

**Query skeleton (logical order matters):**

```sql
SELECT   col, AGG(col) AS a        -- 5. pick columns
FROM     t1 JOIN t2 ON t1.id=t2.id -- 1. sources
WHERE    cond                      -- 2. filter rows (pre-aggregation)
GROUP BY col                       -- 3. group
HAVING   AGG(col) > 10             -- 4. filter groups (post-aggregation)
ORDER BY a DESC                    -- 6. sort
LIMIT    10 OFFSET 20;             -- 7. page
```

**Joins**

| Join | Returns |
|---|---|
| `INNER JOIN` | rows matching in both |
| `LEFT JOIN` | all left + matched right (NULL if none) |
| `RIGHT JOIN` | all right + matched left |
| `FULL OUTER JOIN` | all rows from both sides |
| `CROSS JOIN` | cartesian product |
| self-join | `FROM emp e JOIN emp m ON e.mgr_id=m.id` |

**Aggregates:** `COUNT(*)`, `COUNT(DISTINCT x)`, `SUM`, `AVG`, `MIN`, `MAX`, `STRING_AGG(x,',')`.

**Window functions** (per-row, no collapsing):

```sql
ROW_NUMBER() OVER (PARTITION BY dept ORDER BY salary DESC)  -- 1,2,3 unique
RANK() / DENSE_RANK() OVER (...)                            -- ties: gaps / no gaps
SUM(x) OVER (PARTITION BY dept)                             -- group total on each row
LAG(x,1) / LEAD(x,1) OVER (ORDER BY dt)                     -- prev / next row value
SUM(x) OVER (ORDER BY dt ROWS BETWEEN UNBOUNDED PRECEDING
             AND CURRENT ROW)                               -- running total
```

**DDL / DML**

```sql
CREATE TABLE users (
  id    SERIAL PRIMARY KEY,
  email TEXT UNIQUE NOT NULL,
  age   INT CHECK (age >= 0),
  dept_id INT REFERENCES depts(id),
  created TIMESTAMP DEFAULT now()
);
ALTER TABLE users ADD COLUMN name TEXT;
ALTER TABLE users DROP COLUMN name;
CREATE INDEX idx_users_email ON users(email);
DROP TABLE users;

INSERT INTO users (email) VALUES ('a@b.com');
UPDATE users SET age = 30 WHERE id = 1;
DELETE FROM users WHERE id = 1;
```

**Handy:** `COALESCE(x, 0)` (NULL default) · `CASE WHEN c THEN a ELSE b END` · `x IN (...)` · `x BETWEEN a AND b` · `x LIKE 'a%'` · CTE: `WITH t AS (SELECT ...) SELECT * FROM t` · `UNION` (dedup) vs `UNION ALL` (keep dups). NULL compares with `IS NULL`, never `= NULL`.

## Regular Expressions

> Metacharacters, quantifiers, groups, lookarounds, patterns. Depth: **see Chapter 9.x** (automata & regex).

**Metacharacters / classes**

| Token | Matches |
|---|---|
| `.` | any char (except newline) |
| `\d` `\D` | digit / non-digit |
| `\w` `\W` | word char `[A-Za-z0-9_]` / not |
| `\s` `\S` | whitespace / not |
| `[abc]` `[^abc]` | set / negated set |
| `[a-z]` | range |
| `^` `$` | start / end of line |
| `\b` `\B` | word boundary / not |
| `\.` | literal dot (escape) |

**Quantifiers**

| Token | Repeats |
|---|---|
| `*` | 0 or more |
| `+` | 1 or more |
| `?` | 0 or 1 (optional) |
| `{n}` `{n,}` `{n,m}` | exactly / at least / range |
| `*?` `+?` | lazy (non-greedy) versions |

**Groups & alternation**

```
(abc)          capturing group → backref \1
(?:abc)        non-capturing group
(?P<name>..)   named group (Python) / (?<name>..) (JS,PCRE)
a|b            alternation (a or b)
```

**Lookarounds (zero-width assertions)**

```
(?=foo)    positive lookahead   - followed by foo
(?!foo)    negative lookahead   - NOT followed by foo
(?<=foo)   positive lookbehind  - preceded by foo
(?<!foo)   negative lookbehind  - NOT preceded by foo
```

**Common patterns**

```
Email (rough)   ^[\w.+-]+@[\w-]+\.[\w.-]+$
URL             https?://[^\s]+
IPv4            \b(?:\d{1,3}\.){3}\d{1,3}\b
US phone        \(?\d{3}\)?[-.\s]?\d{3}[-.\s]?\d{4}
Date YYYY-MM-DD \d{4}-\d{2}-\d{2}
Hex color       #[0-9a-fA-F]{6}\b
Trim whitespace ^\s+|\s+$
Leading zeros   ^0+(?=\d)
```

Flags: `i` ignore-case · `g` global · `m` multiline (`^`/`$` per line) · `s` dotall (`.` matches newline).

## C++

> Core syntax + the ownership rules you forget first. Depth: **see Part 29** in reading order: 29.1, 29.5, 29.2, 29.6, 29.3, 29.7, 29.4.

```bash
g++ -std=c++17 -Wall -Wextra -O2 -o prog main.cpp   # build
g++ -std=c++17 -g -fsanitize=address,undefined ...   # debug build with sanitizers
g++ -std=c++17 -pthread ...                          # threads need -pthread
```

| Task | C++ |
|---|---|
| Print | `std::cout << x << "\n";` |
| Formatted vector loop | `for (const auto& v : vec) { ... }` |
| Pass read-only | `void f(const std::string& s)` |
| Pass to modify | `void f(std::string& s)` |
| Own heap object | `auto p = std::make_unique<T>(args);` |
| Shared ownership (rare) | `auto p = std::make_shared<T>(args);` |
| Move, don't copy | `T b = std::move(a);  // a is now valid-but-empty` |
| Dict | `std::unordered_map<K, V>` |
| List | `std::vector<T>` (`reserve()` before big fills) |
| Sort with key | `std::sort(v.begin(), v.end(), [](auto& a, auto& b){ return a.x < b.x; });` |
| String building | `s += piece;` (amortized cheap) |
| Convert | `std::stoi(s)`, `std::to_string(n)` |

**Ownership rules (the ones that bite):**
- Rule of zero: write no destructor/copy/move if members manage themselves.
- Rule of five: write one of destructor/copy-ctor/copy-assign/move-ctor/move-assign, and deal with all five.
- Delete through a base pointer only if the base destructor is `virtual`.
- Never `new`/`delete` by hand in application code: `std::unique_ptr` or a container.
- Polymorphism needs a pointer or reference; passing by value slices.
- A data race (two threads, one location, one write, no synchronization) is undefined behavior, not a stale read. Guard with a `std::mutex` or `std::atomic`.

**Debugging:** `-fsanitize=address` (memory bugs), `-fsanitize=thread` (races), `valgrind ./prog` (leaks), `gdb ./prog` then `run`, `bt`.

## Big-O Complexity

> Common structures & algorithms. Depth: **see Chapter 2.x** (algorithms & complexity).

**Data structure operations (average)**

| Structure | Access | Search | Insert | Delete |
|---|---|---|---|---|
| Array / dynamic array | O(1) | O(n) | O(n)* | O(n) |
| Linked list | O(n) | O(n) | O(1) | O(1) |
| Stack / Queue | O(n) | O(n) | O(1) | O(1) |

**Sorting**

| Algorithm | Best | Average | Worst | Space | Stable |
|---|---|---|---|---|---|
| Quicksort | O(n log n) | O(n log n) | O(n²) | O(log n) | no |
| Mergesort | O(n log n) | O(n log n) | O(n log n) | O(n) | yes |
| Heapsort | O(n log n) | O(n log n) | O(n log n) | O(1) | no |
| Insertion | O(n) | O(n²) | O(n²) | O(1) | yes |
| Bubble | O(n) | O(n²) | O(n²) | O(1) | yes |
| Counting/Radix | O(n+k) | O(n+k) | O(nk) | O(n+k) | yes |

**Searching / common algos**

| Algorithm | Time |
|---|---|
| Binary search (sorted) | O(log n) |
| Linear search | O(n) |
| BFS / DFS (graph) | O(V + E) |
| Dijkstra (heap) | O((V+E) log V) |
| Binary tree traversal | O(n) |

**Growth, slow→fast:** O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!).

## Fab Floor Reference

> Units, formulas, and signal levels for equipment and process work. Depth: **see Part 30** (30.1 electrical, 30.2 chemical, 30.3 mechanical, 30.4 process) and **17.7** (tools and software).

**Key formulas**

| Name | Formula | Use |
|---|---|---|
| Ohm's law | V = IR, P = VI = I²R | every electrical check |
| Three-phase power | P = √3 · V_L · I_L · PF | tool feed sizing |
| Preston's equation | RR = K_p · P · V | CMP removal rate |
| CMP relative speed | \|v_rel\| = ω·d when ω_head = ω_platen | why speeds are matched |
| Reynolds number | Re = ρvD/μ (turbulent above ~4000 in pipe) | slurry line health |
| Continuity | Q = v·A | flow ↔ velocity |
| Force from pressure | F = P·A | cylinders, chucks, downforce |
| Stokes settling | v = (ρ_p − ρ_f) g d² / 18μ | why agglomerates scratch |
| Natural frequency | f = (1/2π)·√(k/m) | vibration, resonance |
| Cpk | min(USL−μ, μ−LSL) / 3σ | capability vs spec |
| MTBF / Availability | MTBF = uptime/failures; A = uptime/total | qual contracts |

**Unit conversions**

| From | To |
|---|---|
| 1 psi | 6.895 kPa ≈ 0.0689 bar |
| 1 atm | 101.325 kPa = 14.7 psi = 760 Torr |
| 1 Torr | 133.3 Pa |
| 1 gpm | 3.785 L/min |
| 1 inch | 25.4 mm |
| °F → °C | (°F − 32) × 5/9 |
| 1 mil | 25.4 µm |
| 1 Å | 0.1 nm |

**Signals and power**

| Standard | Range | Note |
|---|---|---|
| Current loop | 4-20 mA | 4 mA = live zero; 0 mA = broken wire |
| Analog voltage | 0-10 V | cheap, corrupted by wire drop + ground loops |
| Thermocouple | mV-level | needs cold-junction compensation |
| RTD (Pt100) | 100 Ω at 0 °C | more accurate, slower |
| US tool feeds | 480 V / 208 V 3-phase, 60 Hz | Japan: 200 V, 50/60 Hz by region |

**Water/slurry quick facts:** UPW ≈ 18.2 MΩ·cm at 25 °C; pH is a log scale (pH 2 → 10⁻² mol/L H⁺); typical CMP downforce is a few psi; a 300 mm wafer at 2 psi carries ≈ 975 N.

**Safety anchors:** LOTO = lock, tag, verify zero energy, try to start. Never jumper an interlock. Two questions before touching anything: what energy is present, and what is downstream of this valve/breaker?
